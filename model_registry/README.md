# Model Registry

This folder contains resources and documentation for model versioning, lifecycle management, and deployment.

---

## What is a Model Registry?

A model registry is a central place to track, version, and manage ML models from experimentation to production.

---

## Example Tools

- [MLflow Model Registry](https://mlflow.org/docs/latest/model-registry.html)
- [SageMaker Model Registry](https://docs.aws.amazon.com/sagemaker/latest/dg/model-registry.html)

---

## Typical Workflow

1. Register new models after training
2. Transition models through stages (Staging, Production, Archived)
3. Deploy models to production
