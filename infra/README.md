# Infrastructure & Automation

This directory contains infrastructure, orchestration, and automation scripts/configs for the MLOps project.

- `ci_cd/`: CI/CD pipeline configs (e.g., GitHub Actions)
- `orchestration/`: Celery, Redis, and scheduler scripts
- `gpu_management/`: GPU-aware job scheduling
- `docker/`: Dockerfiles for various services
- `k8s/`: Kubernetes manifests (deployment, service, HPA)
