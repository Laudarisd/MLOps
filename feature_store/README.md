# Feature Store

This folder contains resources and documentation for managing and sharing ML features across projects and teams.

---

## What is a Feature Store?
A feature store is a centralized repository for storing, discovering, and serving features for machine learning models. It ensures consistency between training and serving.

---

## Example Tools
- [Feast](https://feast.dev/): Open-source feature store for ML
- Tecton, Hopsworks (commercial options)

---

## Typical Workflow
1. Define features in code or UI
2. Ingest features from data pipelines
3. Serve features to training and inference jobs
